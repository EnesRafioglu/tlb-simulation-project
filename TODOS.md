# Ein paar Grundregeln:

- Jeder arbeitet auf seiner eigenen Branch!
  - https://www.atlassian.com/git/tutorials/using-branches
  - https://code.visualstudio.com/docs/sourcecontrol/overview#_branches-and-tags
- Bevor Code in die main branch gemerged wird erst einmal auf WA schreiben damit der Rest den Code überprüfen kann
- Code der nicht compiled oder Tests failed wird NICHT gemerged
- Für SystemC: Erst entwerfen, dann coden!
